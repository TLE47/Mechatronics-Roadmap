## A–C

| Term | First Taught In | Plain-English Definition |
| :--- | :--- | :--- |
| **Acceleration ($a$)** | [Lesson P.11](../track-p/P.11-reading-time-series-graphs.md) | The rate at which velocity changes over time ($a = \frac{\Delta v}{\Delta t}$), measured in meters per second squared ($\text{m/s}^2$). On a velocity-vs-time graph, acceleration is the **slope** of the line. |
| **Active-Low** | [Lesson S0.7](../stage-0/S0.7-arduino-uno-digital-io-and-pullups.md) | A digital wiring pattern (such as a button with `INPUT_PULLUP` wired to `GND`) where the resting/released state reads `HIGH` ($5.0\text{ V}$) and the active/pressed state pulls the pin down to `LOW` ($0.0\text{ V}$). |
| **ADC (Analog-to-Digital Converter)** | [Lesson S0.8](../stage-0/S0.8-adc-analog-read-and-serial-monitor.md) | Hardware inside a microcontroller that measures a continuous analog voltage ($0.0\text{ V}$ to $5.0\text{ V}$ on the Arduino Uno) and converts it into a whole-number integer (`0` to `1023` for a 10-bit ADC via `analogRead()`). |
| **Ammeter** | [Lesson S0.4](../stage-0/S0.4-multimeters-and-current-limited-supplies.md) | A multimeter mode that measures electric **current** ($I$) in Amperes or milliamps. An ammeter has near-zero internal resistance and **must** be wired **in series** by breaking the circuit loop. |
| **Ampere / Amp (`A`)** | [Lesson P.7](../track-p/P.7-si-units-and-metric-prefixes.md), [S0.1](../stage-0/S0.1-closed-circuits-and-ohms-law.md) | The SI base unit of electric **current** (flow rate of electric charge). $1\text{ A} = 1{,}000\text{ mA}$ (milliamps). |
| **Angular Velocity ($\omega$)** | [Lesson P.10](../track-p/P.10-radians-and-right-triangle-trig.md) | Rotational speed measured in **radians per second (`rad/s`)**. Converted from revolutions per minute (`RPM`) via $\omega = \text{RPM} \times \frac{2\pi}{60}$. |
| **Anode (`+`)** | [Lesson S0.2](../stage-0/S0.2-leds-and-resistor-power.md) | The positive terminal of a diode, LED (longer leg), or polarized capacitor where conventional current enters during forward operation. |
| **`assert`** | [Lesson P.6](../track-p/P.6-modules-and-automated-asserts.md) | A Python keyword (`assert condition`) that automatically verifies a condition is `True`; if `False`, Python immediately stops with an `AssertionError` so calculation bugs are caught immediately. |
| **Assignment (`=`)** | [Lesson P.1](../track-p/P.1-variables-and-data-types.md) | The single equals sign `=` in code, which evaluates the expression on the right-hand side first and stores the result into the variable named on the left-hand side. |
| **Baud Rate** | [Lesson S0.8](../stage-0/S0.8-adc-analog-read-and-serial-monitor.md) | The communication speed of a serial link in **bits per second** (e.g., `Serial.begin(9600)` transmits 9,600 bits per second). |
| **Binary** | [Lesson P.8](../track-p/P.8-frequency-and-binary-bits.md) | The base-2 number system (`0` and `1`) used by digital electronics, where each position represents a power of 2 ($1, 2, 4, 8, 16, \dots$). |
| **Bit & Byte** | [Lesson P.8](../track-p/P.8-frequency-and-binary-bits.md) | A **bit** (binary digit) is a single `0` or `1` state. A **byte** is a group of 8 bits ($2^8 = 256$ combinations, `0` to `255`). |
| **`bool` (Boolean)** | [Lesson P.1](../track-p/P.1-variables-and-data-types.md) | A data type that can only hold one of two truth values: `True` or `False`. |
| **Breadboard** | [Lesson S0.3](../stage-0/S0.3-breadboards-and-short-circuits.md) | A reusable solderless plastic board with internal metal spring clips: outer **power rails** run vertically along the edges, while inner **terminal rows** connect 5 holes horizontally (`a–e` and `f–j`) on either side of a center ravine. |
| **Brownout** | [Lesson S0.6](../stage-0/S0.6-capacitors-and-decoupling.md) | A temporary drop (sag) in power-supply voltage ($5.0\text{ V}$ dipping below the microcontroller's minimum operating threshold) caused by a sudden surge in current demand, often resetting the MCU. |
| **Capacitor & Capacitance ($C$)** | [Lesson S0.6](../stage-0/S0.6-capacitors-and-decoupling.md) | A two-terminal component made of conductive plates separated by an insulator that stores electric charge ($Q = C \cdot V$) and **resists sudden changes in voltage**. Capacitance $C$ is measured in **Farads (`F`)**, typically `µF` ($10^{-6}\text{ F}$) or `nF` ($10^{-9}\text{ F}$). |
| **Cathode (`-`)** | [Lesson S0.2](../stage-0/S0.2-leds-and-resistor-power.md) | The negative terminal of a diode (marked with a painted band/stripe) or LED (shorter leg, flat rim) where conventional current exits when forward-biased. |
| **CC/CV (Constant-Current / Constant-Voltage) Supply** | [Lesson S0.4](../stage-0/S0.4-multimeters-and-current-limited-supplies.md) | A benchtop DC power supply with both a voltage setpoint ($V_{\text{set}}$) and a current limit ($I_{\text{limit}}$). Under normal load ($I < I_{\text{limit}}$) it regulates Constant Voltage (`CV`); during an overload or short circuit it switches to Constant Current (`CC`), folding voltage down to $I_{\text{limit}} \cdot R_{\text{load}}$. |
| **Clamping (Saturation)** | [Lesson P.3](../track-p/P.3-decisions-and-clamping.md) | Using `if / elif` logic to restrict a number so it never exceeds a safe maximum or falls below a safe minimum (such as clamping PWM commands to `[0, 255]`). |
| **Comment (`#` or `//`)** | [Lesson P.1](../track-p/P.1-variables-and-data-types.md), [S0.7](../stage-0/S0.7-arduino-uno-digital-io-and-pullups.md) | Human-readable notes in source code (after `#` in Python or `//` in C/C++) that the computer completely ignores when running the program. |
| **Common Ground** | [Lesson 01.1](../01-electronics-and-power/01.1-mosfet-inductor-flyback.md) | Connecting the negative (`0 V` / `GND`) terminals of two different power supplies (such as a $5\text{ V}$ Arduino and a $12\text{ V}$ motor battery) together so control signals share a single $0.0\text{ V}$ reference. |
| **Comparison Operators** | [Lesson P.3](../track-p/P.3-decisions-and-clamping.md) | Symbols that compare two values and evaluate to `True` or `False`: `==` (equal to), `!=` (not equal to), `<`, `<=`, `>`, `>=`. |
| **Conditional Statement (`if/elif/else`)** | [Lesson P.3](../track-p/P.3-decisions-and-clamping.md) | A programming structure that tests a boolean condition and runs an indented block of code only when that condition is `True`. |
| **Continuity Mode** | [Lesson S0.4](../stage-0/S0.4-multimeters-and-current-limited-supplies.md) | A multimeter setting (used with circuit power **OFF**) that sounds an audible beep when two probes touch points connected by near-zero resistance ($R \approx 0\ \Omega$). |
| **Cosine (`cos`)** | [Lesson P.10](../track-p/P.10-radians-and-right-triangle-trig.md) | In a right triangle at angle $\theta$ measured from the horizontal, the ratio $\frac{\text{adjacent}}{\text{hypotenuse}}$; gives the horizontal coordinate and perpendicular gravity lever arm $r_\perp = x = L\cos(\theta)$ of a link of length $L$. |
| **Current ($I$)** | [Lesson S0.1](../stage-0/S0.1-closed-circuits-and-ohms-law.md) | The flow rate of electric charge through a conductor, measured in **Amperes (`A`)** or **milliamps (`mA`)**. |
| **Current-Limiting Resistor** | [Lesson S0.2](../stage-0/S0.2-leds-and-resistor-power.md) | A resistor placed in series with an LED ($R = \frac{V_{\text{supply}} - V_f}{I_{\text{target}}}$) to keep current at a safe level (typically $10\text{–}20\text{ mA}$). |

## D–I

| Term | First Taught In | Plain-English Definition |
| :--- | :--- | :--- |
| **DC (Direct Current)** | [Lesson S0.1](../stage-0/S0.1-closed-circuits-and-ohms-law.md) | Steady, one-direction electrical supply (such as a $5.0\text{ V}$ USB rail or $12.0\text{ V}$ battery) where positive and negative terminals do not swap polarity over time. |
| **Decoupling (Bypass) Capacitor** | [Lesson S0.6](../stage-0/S0.6-capacitors-and-decoupling.md) | A capacitor placed in parallel right across `VCC` (`5V`) and `GND` near a chip or motor driver to act as a local charge reservoir that absorbs sudden current spikes and prevents voltage brownouts. |
| **Displacement ($\Delta x$)** | [Lesson P.11](../track-p/P.11-reading-time-series-graphs.md) | Net change in position ($x_{\text{now}} - x_{\text{prev}}$), equal to the **area** under a velocity-vs-time graph ($\Delta x = v \cdot \Delta t$). |
| **Drain (`D`)** | [Lesson 01.1](../01-electronics-and-power/01.1-mosfet-inductor-flyback.md) | The terminal of an N-Channel MOSFET that connects to the negative side of the load (motor coil); current flows from Drain to Source when the Gate is driven `HIGH`. |
| **Duty Cycle** | [Lesson S0.9](../stage-0/S0.9-pwm-duty-cycle-and-analog-write.md) | The fraction or percentage of each PWM period $T$ during which the signal stays `HIGH` ($\text{Duty} = \frac{T_{\text{on}}}{T} \times 100\%$). |
| **Electrolytic Capacitor** | [Lesson S0.6](../stage-0/S0.6-capacitors-and-decoupling.md) | A high-capacitance (typically $10\ \mu\text{F}\text{–}1000\ \mu\text{F}$) cylindrical **polarized** capacitor whose negative (`-`) stripe leg must always connect to the lower voltage (`GND`). |
| **`f-string` (Formatted String)** | [Lesson P.1](../track-p/P.1-variables-and-data-types.md) | A Python text string prefixed with `f` (e.g., `f"V = {volts:.2f}"`) that substitutes expressions inside `{}` directly into the output text. |
| **`float` (Floating-Point Number)** | [Lesson P.1](../track-p/P.1-variables-and-data-types.md) | A number with a decimal point (e.g., `12.0`, `-0.05`, `3.14159`) used to represent continuous physical measurements. |
| **Floating Pin** | [Lesson S0.7](../stage-0/S0.7-arduino-uno-digital-io-and-pullups.md) | A digital input pin that is not connected to either `5V` or `GND` (for example, when a button is open and no pull-up/pull-down resistor is enabled), causing it to pick up stray electrical noise and randomly flip between `HIGH` and `LOW`. |
| **Flyback Diode (Freewheeling Diode)** | [Lesson 01.1](../01-electronics-and-power/01.1-mosfet-inductor-flyback.md) | A diode wired in parallel across an inductive load (like a motor coil or solenoid) with its **cathode stripe (`-`) facing $+V_{\text{supply}}$**, giving coil current a safe recirculation path when the MOSFET switches OFF and clamping inductive voltage spikes. |
| **`for` Loop** | [Lesson P.4](../track-p/P.4-lists-and-for-loops.md) | A loop that repeats an indented block of code once for each item in a sequence (`for x in list:`) or each integer in `range(n)`. |
| **Force ($F$)** | [Lesson P.12](../track-p/P.12-forces-and-lever-torque.md) | A linear push or pull measured in **Newtons (`N`)**, related to mass and acceleration by Newton's Second Law ($F_{\text{net}} = m \cdot a$). |
| **Forward Voltage ($V_f$)** | [Lesson S0.2](../stage-0/S0.2-leds-and-resistor-power.md) | The fixed voltage drop consumed across a conducting diode or LED ($\approx 2.0\text{ V}$ for a red LED; $\approx 0.7\text{ V}$ for a silicon flyback diode). |
| **Four-Quadrant Inverse Tangent (`atan2`)** | [Lesson P.10](../track-p/P.10-radians-and-right-triangle-trig.md) | The function `math.atan2(y, x)` that computes the angle $\theta \in [-\pi, +\pi]\text{ rad}$ (measured from the positive horizontal $x$-axis) to point $(x, y)$ safely in all four quadrants without dividing by zero when $x = 0$. |
| **Frequency ($f$) & Hertz (`Hz`)** | [Lesson P.8](../track-p/P.8-frequency-and-binary-bits.md) | How many repeating cycles occur in one second, measured in **Hertz (`Hz`, $1\text{ Hz} = 1\text{ cycle/s}$)**. Frequency is the reciprocal of period: $f = \frac{1}{T}$. |
| **Function (`def` / `return`)** | [Lesson P.5](../track-p/P.5-functions-and-while-loops.md) | A named, reusable block of code that accepts input **parameters**, performs a calculation, and hands back an output value via `return`. |
| **Gate (`G`)** | [Lesson 01.1](../01-electronics-and-power/01.1-mosfet-inductor-flyback.md) | The control input terminal of a MOSFET; raising the Gate-to-Source voltage ($V_{\text{GS}}$) to $5.0\text{ V}$ on a logic-level N-Channel MOSFET turns the Drain-to-Source switch ON. |
| **GPIO (General-Purpose Input/Output)** | [Lesson S0.7](../stage-0/S0.7-arduino-uno-digital-io-and-pullups.md) | Pins on a microcontroller (such as Pins `0`–`13` and `A0`–`A5` on the Arduino Uno) that software can configure as inputs (to read sensors/buttons) or outputs (to drive LEDs/MOSFETs). |
| **Ground (`GND`)** | [Lesson S0.1](../stage-0/S0.1-closed-circuits-and-ohms-law.md) | The common **$0.0\text{ V}$ reference point** and return path in an electrical circuit against which all other voltages are measured. |
| **Hypotenuse** | [Lesson P.10](../track-p/P.10-radians-and-right-triangle-trig.md) | The longest side of a right triangle (opposite the $90^\circ$ corner), corresponding to the physical length $L$ of a tilted robot arm link. |
| **Indentation** | [Lesson P.3](../track-p/P.3-decisions-and-clamping.md) | Leading spaces (4 spaces per level in Python) at the start of a line that tell Python which statements belong inside an `if`, `for`, `while`, or `def` block. |
| **Inductive Kickback** | [Lesson 01.1](../01-electronics-and-power/01.1-mosfet-inductor-flyback.md) | The high-voltage spike ($V_L = L \frac{\Delta I}{\Delta t}$) generated by an inductor (motor coil) when its current is abruptly switched off, capable of destroying transistors unless clamped by a flyback diode. |
| **Inductor & Inductance ($L$)** | [Lesson 01.1](../01-electronics-and-power/01.1-mosfet-inductor-flyback.md) | A coil of wire (such as a motor winding or solenoid) that stores energy in a magnetic field and **resists sudden changes in current** ($V_L = L \frac{\Delta I}{\Delta t}$). Inductance $L$ is measured in **Henries (`H`)** or **millihenries (`mH`, $10^{-3}\text{ H}$)**. |
| **`int` (Integer)** | [Lesson P.1](../track-p/P.1-variables-and-data-types.md) | A positive, negative, or zero whole number with no decimal point (e.g., `0`, `255`, `-40`, `1023`). |
| **Integer Division** | [Lesson S0.8](../stage-0/S0.8-adc-analog-read-and-serial-monitor.md), [S0.M](../stage-0/S0.M-stage-0-milestone.md) | Dividing two whole integers where the fractional remainder is discarded (written `a / b` on `int` variables in C/C++, or `a // b` in Python, so `1023 / 4` equals `255`). |

## K–Z

| Term | First Taught In | Plain-English Definition |
| :--- | :--- | :--- |
| **Kirchhoff's Laws** | [Lesson S0.5](../stage-0/S0.5-series-parallel-and-voltage-dividers.md) | Two physical conservation rules for circuits: (1) all voltage drops around any closed series loop sum to the supply voltage, and (2) all currents entering a parallel junction node equal all currents leaving that node. |
| **LED (Light-Emitting Diode)** | [Lesson S0.2](../stage-0/S0.2-leds-and-resistor-power.md) | A semiconductor diode that emits light when current flows forward from its **anode (`+`)** to its **cathode (`-`)**, requiring a series resistor to limit current. |
| **Lever Arm ($r_\perp$)** | [Lesson P.12](../track-p/P.12-forces-and-lever-torque.md) | The **perpendicular distance** in meters (`m`) from a rotational pivot/joint axis to the line of action of a force. For a link of length $L$ at angle $\theta$ measured from the **horizontal** holding a vertical gravity load $W = mg$, the perpendicular horizontal lever arm is $r_\perp = L\cos\theta$. |
| **Linear Scaling** | [Lesson P.9](../track-p/P.9-rearranging-formulas-and-scaling.md) | Mapping a number proportionally from one interval $[x_{\min}, x_{\max}]$ to another $[y_{\min}, y_{\max}]$ using its fraction of full scale. |
| **`list` & Zero-Based Indexing** | [Lesson P.4](../track-p/P.4-lists-and-for-loops.md) | An ordered collection of items in square brackets `[a, b, c]` where position counting starts at **index `0`** (`items[0]` is the first item). |
| **Mass ($m$) vs. Weight ($W$)** | [Lesson P.12](../track-p/P.12-forces-and-lever-torque.md) | **Mass** ($m$, in `kg`) is the amount of matter (inertia) in an object; **weight** ($W = m \cdot g$, in Newtons `N`, with $g = 9.81\text{ m/s}^2$) is the downward gravitational force pulling on that mass. |
| **Metric Prefixes (`M`, `k`, `m`, `µ`, `n`)** | [Lesson P.7](../track-p/P.7-si-units-and-metric-prefixes.md), [S0.6](../stage-0/S0.6-capacitors-and-decoupling.md) | Powers-of-10 multipliers attached to units: **mega (`M`)** $= 10^6$, **kilo (`k`)** $= 10^3$, **milli (`m`)** $= 10^{-3}$, **micro (`µ`)** $= 10^{-6}$, **nano (`n`)** $= 10^{-9}$. |
| **Microcontroller (`MCU`)** | [Lesson S0.7](../stage-0/S0.7-arduino-uno-digital-io-and-pullups.md) | A compact single-chip computer (such as the `ATmega328P` on the Arduino Uno) containing a CPU, memory, ADC, timers, and GPIO pins designed to sense and control hardware directly. |
| **Module (`import`)** | [Lesson P.6](../track-p/P.6-modules-and-automated-asserts.md) | A built-in or external library of functions and constants loaded into a Python script using `import` (such as `import math`). |
| **MOSFET (N-Channel)** | [Lesson 01.1](../01-electronics-and-power/01.1-mosfet-inductor-flyback.md) | Metal-Oxide-Semiconductor Field-Effect Transistor: a 3-pin (`Gate`, `Drain`, `Source`) voltage-controlled electronic switch with very low on-resistance ($R_{\text{DS(on)}}$) used to switch high motor currents from a low-current microcontroller pin. |
| **Node** | [Lesson S0.3](../stage-0/S0.3-breadboards-and-short-circuits.md) | Any continuous metal connection path (such as a 5-hole breadboard strip) shared by two or more component legs; every point on the same node is at the same voltage. |
| **Ohm (`Ω`) & Resistance ($R$)** | [Lesson S0.1](../stage-0/S0.1-closed-circuits-and-ohms-law.md) | Opposition to electric current flow, measured in **Ohms (`Ω`)**. |
| **Ohm's Law ($V = I \cdot R$)** | [Lesson S0.1](../stage-0/S0.1-closed-circuits-and-ohms-law.md) | The fundamental law relating voltage drop ($V$, in Volts), current ($I$, in Amperes), and resistance ($R$, in Ohms): $V = I \cdot R$, $I = \frac{V}{R}$, and $R = \frac{V}{I}$. |
| **Open Circuit** | [Lesson S0.1](../stage-0/S0.1-closed-circuits-and-ohms-law.md), [S0.3](../stage-0/S0.3-breadboards-and-short-circuits.md) | A broken or disconnected electrical path ($R = \infty$) through which zero current can flow. |
| **Parameter** | [Lesson P.5](../track-p/P.5-functions-and-while-loops.md) | A named input variable listed inside the parentheses of a function definition `def func(param):`. |
| **Period ($T$)** | [Lesson P.8](../track-p/P.8-frequency-and-binary-bits.md) | The time duration required to complete one full repeating cycle, measured in seconds (`s`, `ms`, or `µs`). $T = \frac{1}{f}$. |
| **Potentiometer** | [Lesson S0.5](../stage-0/S0.5-series-parallel-and-voltage-dividers.md) | A 3-terminal variable resistor with a rotating or sliding center contact (**wiper**) that acts as an adjustable voltage divider between `VCC` and `GND`. |
| **Power ($P$) & Watt (`W`)** | [Lesson S0.2](../stage-0/S0.2-leds-and-resistor-power.md) | The rate at which electrical energy is converted into heat or mechanical work, measured in **Watts (`W`)**: $P = V \cdot I = I^2 \cdot R$. |
| **Pull-Up / Pull-Down Resistor** | [Lesson S0.7](../stage-0/S0.7-arduino-uno-digital-io-and-pullups.md), [01.1](../01-electronics-and-power/01.1-mosfet-inductor-flyback.md) | A resistor ($10\text{ k}\Omega\text{–}50\text{ k}\Omega$) that gently ties a digital input pin to `5V` (**pull-up**, e.g., `INPUT_PULLUP`) or a MOSFET Gate to `GND` (**pull-down**) so the pin has a known default state when switches are open. |
| **PWM (Pulse-Width Modulation)** | [Lesson S0.9](../stage-0/S0.9-pwm-duty-cycle-and-analog-write.md) | Rapidly switching a digital pin between `HIGH` ($5.0\text{ V}$) and `LOW` ($0.0\text{ V}$) at fixed frequency so a load responds to the smooth average voltage $V_{\text{avg}} = \text{Duty} \times V_{\text{cc}}$. |
| **Quantization Step ($1\text{ LSB}$)** | [Lesson S0.8](../stage-0/S0.8-adc-analog-read-and-serial-monitor.md) | The voltage width of a single integer count on an ADC ($\frac{5.0\text{ V}}{1023} \approx 4.89\text{ mV}$ on a 10-bit $5.0\text{ V}$ Arduino Uno). |
| **Radian (`rad`)** | [Lesson P.10](../track-p/P.10-radians-and-right-triangle-trig.md) | The natural unit of angle equal to the arc length along a unit circle: a full circle ($360^\circ$) is $2\pi\text{ rad}$, a half circle ($180^\circ$) is $\pi\text{ rad}$, and a right angle ($90^\circ$) is $\pi/2\text{ rad}$. |
| **$RC$ Time Constant ($\tau = R \cdot C$)** | [Lesson S0.6](../stage-0/S0.6-capacitors-and-decoupling.md) | The product of resistance $R$ (in $\Omega$) and capacitance $C$ (in $\text{F}$), giving the time in seconds required for a charging capacitor to cover $\approx 63.2\%$ of its voltage step ($\approx 99.3\%$ in $5\,\tau$). |
| **RPM (Revolutions Per Minute)** | [Lesson P.10](../track-p/P.10-radians-and-right-triangle-trig.md) | How many full $360^\circ$ ($2\pi\text{ rad}$) turns a shaft completes in 60 seconds; $60\text{ RPM} = 1\text{ rev/s} = 2\pi\text{ rad/s}$. |
| **Schematic** | [Lesson S0.3](../stage-0/S0.3-breadboards-and-short-circuits.md) | A standardized engineering drawing that uses symbols and lines to show the logical electrical connections between components. |
| **Series vs. Parallel** | [Lesson S0.5](../stage-0/S0.5-series-parallel-and-voltage-dividers.md) | **Series** components are connected end-to-end in a single chain (same current $I$, voltages add); **parallel** components are connected side-by-side across the same two nodes (same voltage $V$, currents add). |
| **Short Circuit** | [Lesson S0.3](../stage-0/S0.3-breadboards-and-short-circuits.md) | An unintended near-zero-resistance path ($R \approx 0\ \Omega$) between two different voltages (such as `5V` and `GND`) or across a component's legs, causing excessive current flow or bypassing the component. |
| **SI Base Units** | [Lesson P.7](../track-p/P.7-si-units-and-metric-prefixes.md) | The standard un-prefixed units required in physics equations: meters (`m`), kilograms (`kg`), seconds (`s`), amperes (`A`), volts (`V`), ohms (`Ω`), Hertz (`Hz`), and Newton-meters ($\text{N}\cdot\text{m}$). |
| **Sine (`sin`)** | [Lesson P.10](../track-p/P.10-radians-and-right-triangle-trig.md) | In a right triangle at angle $\theta$ measured from the horizontal, the ratio $\frac{\text{opposite}}{\text{hypotenuse}}$; gives the vertical coordinate $y = L\sin(\theta)$ of a link of length $L$. |
| **Slope ($\Delta y / \Delta t$)** | [Lesson P.11](../track-p/P.11-reading-time-series-graphs.md) | The steepness ($\frac{\text{rise}}{\text{run}}$) of a graph; on a time-series plot, slope equals the **rate of change** (slope of position is velocity; slope of velocity is acceleration). |
| **Source (`S`)** | [Lesson 01.1](../01-electronics-and-power/01.1-mosfet-inductor-flyback.md) | The terminal of an N-Channel MOSFET that connects to **common ground (`GND`)**. |
| **`str` (String)** | [Lesson P.1](../track-p/P.1-variables-and-data-types.md) | A sequence of text characters enclosed in single or double quotes (`"IDLE"`, `'V'`). |
| **Time Step ($\Delta t$ or `dt_s`)** | [Lesson P.11](../track-p/P.11-reading-time-series-graphs.md) | The small elapsed time interval (in seconds) between two consecutive simulation steps or control-loop ticks. |
