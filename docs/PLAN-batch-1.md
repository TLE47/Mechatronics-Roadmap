# PLAN — Batch 1: Tracks 00, 01 (01.2–01.4), and 02 (Tier 1 Only)

This plan specifies the Tier 1 beginner lesson sequence for **Track 00 (`00-foundations`)**, **Track 01 (`01-electronics-and-power`, continuing after `01.1`)**, and **Track 02 (`02-mechanics-kinematics-dynamics`)**, following **Track P (`P.1–P.12 + P.M`)** and **Stage 0 (`S0.1–S0.9 + S0.M`)**.

```mermaid
flowchart LR
    TP["Track P: P.1 - P.M"] --> S0["Stage 0: S0.1 - S0.M"]
    S0 --> T00["Track 00: 00.1 - 00.3"]
```

4. **Track 01 (`01-electronics-and-power/`, Tier 1):** `01.1` $\rightarrow$ `01.2` $\rightarrow$ `01.3` $\rightarrow$ `01.4`
5. **Track 02 (`02-mechanics-kinematics-dynamics/`, Tier 1):** `02.1` $\rightarrow$ `02.2` $\rightarrow$ `02.3` $\rightarrow$ `02.4` $\rightarrow$ `02.5`

## Audit Jargon Removed from Tier 1 (Kept Untouched Under `Advanced (Later)`)
- **Track 00:** Removed Laplace variable $s$, state-space matrices, bond-graph causality strokes, and phase-space energy ellipses from Tier 1.
- **Track 01:** Removed complex numbers ($j\omega$), decibels ($\text{dB}$ / $-3\text{ dB}$ / $-20\text{ dB/decade}$), and Bode log-log asymptotes from Tier 1 (`01.4` uses plain amplitude ratio $\frac{V_{\text{out}}}{V_{\text{in}}} = \frac{1}{\sqrt{1 + (f/f_c)^2}}$ at $f_c = \frac{1}{2\pi R C}$, where $f = f_c$ gives $70.7\%$ amplitude).
- **Track 02:** Removed $\text{SO}(2)/\text{SO}(3)$ Lie group notation, matrix multiplication, Jacobian determinants ($\det J(\theta)$), null spaces, and Euler-Bernoulli beam deflection formulas ($\delta = \frac{FL^3}{3EI}$, $I = \frac{bh^3}{12}$) from Tier 1; ramped kinematics gently as **1-link FK (`02.1`) $\rightarrow$ 2-link FK (`02.2`) $\rightarrow$ 2-link IK (`02.3`)**.
